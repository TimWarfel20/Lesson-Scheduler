### Lesson Scheduler

This is an email parser I built while working at iD Tech. The purpose of the project was to parse emails regarding lesson bookings and add them to my google calendar. 
The project can handle the following with some difficulty:

- New Scheduling
- Reschedules
- Cancellations

I utilized several magic numbers and other design flaws while creating this program. 
As of now, it is no longer in use or active development as I have ceased employment at iD Tech. 
Its public status is for anyone who would like to build upon this program and my own development archives.
